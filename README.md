# PokéTeam Lab

Pokédex est une application web développée avec React qui utilise les données de [PokéAPI](https://pokeapi.co/) pour explorer l’univers Pokémon.

L’objectif du projet est de proposer davantage qu’un Pokédex classique. L’application permettra de rechercher des Pokémon, consulter leurs caractéristiques, composer une équipe et analyser ses forces et ses faiblesses.

> Le projet est actuellement en cours de développement.

## Fonctionnalités prévues

- Explorer et rechercher des Pokémon
- Filtrer les Pokémon par type et génération
- Consulter leurs informations et statistiques
- Ajouter jusqu’à six Pokémon à une équipe
- Analyser les types, résistances et faiblesses de l’équipe
- Comparer plusieurs Pokémon
- Enregistrer une équipe et des favoris dans le navigateur

## Technologies utilisées

- React
- Vite
- Tailwind CSS
- PokéAPI
- JavaScript

## Installation

Cloner le projet puis installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```

L’application sera accessible à l’adresse indiquée par Vite, généralement :

```text
http://localhost:5173
```

## Source des données

Les informations et illustrations utilisées par l’application proviennent de [PokéAPI](https://pokeapi.co/).

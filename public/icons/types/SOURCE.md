# Pokémon type icons

Source: https://github.com/duiker101/pokemon-type-svg-icons
Author: duiker101
Revision: 5781623f147f1bf850f426cfe1874ba56a9b75ee

The 18 SVG files are copied unchanged from the repository's icons directory.
Its README links the original artwork to https://dribbble.com/shots/7635664-Pokemon-Types
and describes the set as "for any use". No explicit LICENSE file was found
in the repository at the time of integration. This attribution is not a license grant.

The application serves these assets locally and uses CSS masks to apply its
existing type colors, without loading the repository's demo styles.
